# صانع الشورتس (Shorts Maker)

صفحة ويب تعمل محلياً على جهازك: ترفع فيديو طويلاً أو تلصق رابط يوتيوب، فيحوّله إلى شورتس عمودية 9:16
بهوك وكابشنز متحركة ومؤثرات تلقائية.

## المزايا

- **التفريغ النصي** بتوقيت كل كلمة (AssemblyAI)، يدعم العربية.
- **اختيار أقوى المقاطع** وكتابة الهوك والعنوان (Gemini)، مع تقسيم الفيديوهات الطويلة لأجزاء.
- **الوصف والهاشتاجات** (Groq).
- **قص عمودي 9:16** مع تتبع الوجه (OpenCV).
- **كابشنز متحركة** كلمة بكلمة، بخمسة أنماط، مع اتجاه عربي صحيح وتلوين الكلمات المفتاحية.
- **حذف الصمت وكلمات الحشو** تلقائياً.
- **المخرج الذكي**: يقرر Gemini لحظات التقريب السريع والوميض والمؤثرات الصوتية.
- **مكتبة مؤثرات وموسيقى**: ضع ملفاتك في `sfx/` و`music/`.
- **حفظ تلقائي للمشاريع** وتحرير نص الكابشنز وإعادة التصيير.

## المتطلبات

- Python 3.10 أو أحدث
- [FFmpeg](https://ffmpeg.org/) (يجب أن يعمل الأمر `ffmpeg -version`)
- مفاتيح API: AssemblyAI وGemini (إلزامية)، وGroq (اختياري)

## التشغيل

```bash
python -m venv venv
venv\Scripts\activate        # على ماك/لينكس: source venv/bin/activate
pip install -r requirements.txt
python -m uvicorn server:app --port 8000
```

ثم افتح `http://localhost:8000` وأدخل المفاتيح في الصفحة.

للفتح من هاتف على نفس الشبكة: شغّل بـ `--host 0.0.0.0` ولا تعرّض المنفذ للإنترنت مباشرة.

## هيكل المشروع

```
server.py          السيرفر (FastAPI) ومسار المعالجة
static/index.html  الواجهة
requirements.txt   المتطلبات
jobs/              المشاريع الناتجة (تُنشأ تلقائياً، غير مرفوعة)
sfx/  music/       مكتبة الأصوات والموسيقى (تُنشأ تلقائياً)
```

## ملاحظات

- المفاتيح تُرسل من الصفحة إلى السيرفر المحلي فقط ثم إلى الخدمات نفسها. خيار «تذكّر المفاتيح»
  يحفظها في متصفحك عبر localStorage، فلا تفعّله على جهاز مشترك.
- تتبع الوجه يحتاج OpenCV 4 (`opencv-python-headless<5`)، فإن لم يعمل يرجع المشروع للقص من المنتصف.
- تأكد من حقوق الموسيقى والمؤثرات الصوتية التي تضيفها قبل نشر الشورتس.
- لم يُصمَّم المشروع للنشر المباشر على الإنترنت: لا توجد حماية بكلمة مرور.
